# 사용자 안내서

이 문서는 여행 참가자의 사용 절차를 관리합니다. 서버 설정과 테스트는 [운영 안내서](OPERATIONS_KO.md), 내부 동작은 [기술 설명서](PROJECT_GUIDE_KO.md)를 참고하세요.

<a id="planning-policy"></a>

## 여행 자료 관리 원칙

운영 중인 여행의 최신 확정 내용은 앱에서 공유 저장한 내용을 기준으로 합니다.

| 내용 | 관리할 곳 |
|---|---|
| 확정 일정·시간·장소 | 앱의 일정 |
| 준비물·해야 할 일·완료 여부 | 앱의 PREP |
| 실제 지출 | 앱의 가계부 |
| 후보 동선·숙소·관광지 비교, 예상 비용 검토 | `planning`의 여행별 자료 |
| 예약 확인서·참고 링크·선택이나 변경의 이유 | `planning`의 여행별 자료 |

확정한 일정은 앱에서 수정하고 저장합니다. `planning`에는 필요한 근거만 남기며, 전체 일정이나 실제 지출을 두 곳에 중복해서 갱신하지 않습니다. 예를 들어 숙소를 바꾸면 앱의 숙소·일정을 수정하고, `planning`에는 새 예약 확인서와 변경 이유를 보관합니다.

앱은 로그인 없이 열람할 수 있으므로 예약 확인서 원본과 개인 정보는 `planning`에 보관하고, 앱에는 이동·체크인에 필요한 공개 가능한 내용만 적습니다. 기존 계획 파일을 정리하는 절차는 [운영 안내서](OPERATIONS_KO.md#planning-transition)를 참고하세요.

## 화면과 탐색

배포된 주소를 열면 로그인 없이 일정을 볼 수 있습니다. 편집은 지정된 Supabase 편집자 계정으로 로그인해야 합니다.

- 여행 전에는 PREP, 여행 중에는 미국 서부 현지 날짜의 일정, 여행 후에는 가계부가 첫 화면으로 열립니다.
- 본문 아래쪽에서 날짜·PREP·가계부 탭을 바꾸면 탭 바가 화면 상단에 오도록 이동합니다. 모션 감소 설정에서는 즉시 이동하며, 제목이 보이는 위치에서 전환하면 그 위치를 유지합니다.
- 헤더에는 서울과 미국 서부의 현재 시각 및 자동 계산된 시차가 표시됩니다.

## 편집·초안·로그아웃

일정은 `편집 시작` 후 수정합니다. 완료 시 변경이 있으면 `저장하고 종료`, `계속 편집`, `변경사항 폐기`를 선택합니다. `초기화`는 현재 초안을 마지막 저장본으로 되돌립니다.

- 일정·가계부 편집 내용은 브라우저 IndexedDB에 탭별 초안으로 유지되며, 확인 후 `저장`해야 공개 페이지에 반영됩니다. 새로고침이나 탭 종료 뒤에도 로그인 상태에서 복구를 제안합니다. 로그아웃 상태라면 편집을 시작해 다시 로그인한 뒤 복구할 수 있습니다. 복구 안내를 Esc로 닫으면 초안은 보관되며, `초안 삭제`를 선택해야 삭제됩니다. 보류한 초안이 있으면 새 편집 전에 복구 또는 삭제를 다시 선택합니다. 다른 열린 탭의 초안은 덮어쓰거나 삭제하지 않으며, 실행 취소로 변경을 모두 되돌리면 복구 대상에서도 제거됩니다.
- 편집 중에는 실행 취소와 다시 실행을 사용할 수 있습니다.
- 다른 탭의 로그아웃이나 인증 종료로 편집이 중단되면 이 탭의 초안을 보관하고 마지막 저장본을 표시합니다. 다시 로그인해 일정·가계부를 편집하거나 편집본을 불러오기 전에 보관한 초안을 복구하거나 삭제해야 합니다. 복구 안내를 닫으면 초안을 유지하고 새 작업은 시작하지 않습니다.
- 로그인 세션은 편집 완료 후에도 유지됩니다. 수동·자동 로그아웃은 현재 브라우저 세션에만 적용되며, 같은 브라우저의 탭에는 동기화됩니다. 마지막 활동 후 29분에 경고하고 30분에 자동 로그아웃합니다. 초안은 이 브라우저에 보관하며, 다시 로그인한 뒤 복구할 수 있습니다. 경고나 수동 로그아웃에서 `폐기 후 로그아웃`을 직접 선택한 경우에는 초안을 삭제합니다.
- 사진 업로드 이후 공유 문서 저장 요청에 12초 안에 응답이 없으면 요청을 중단하고 최신 저장본을 재조회합니다. 저장 내용이 확인되면 완료로 처리하고, 확인되지 않으면 초안을 유지합니다. 연결을 확인한 뒤 다시 저장할 수 있으며, 다른 변경이 있으면 충돌 확인이 필요합니다.

다른 사람이 먼저 저장하면 충돌 안내에서 최신본과 내 초안을 확인하고 재적용 여부를 선택합니다. 초안은 기기 간 백업이 아니므로 중요한 변경은 공유 저장하거나 오프라인 작업본으로 내보내세요.

`초안 보관 실패`가 표시되면 최신 편집은 현재 탭에만 남을 수 있습니다. 새로고침하거나 탭을 닫기 전에 공유 저장하거나 오프라인 작업본으로 내보내세요. 저장 공간 문제를 해결한 뒤 다시 편집하면 초안 보관을 재시도합니다. 새로고침으로 복구되는 내용은 마지막으로 보관에 성공한 초안입니다. `초안 삭제 실패`가 표시되면 폐기·폐기 후 로그아웃은 완료되지 않으며, 저장 공간을 확인하고 다시 시도해야 합니다. 공유 저장이 성공해도 이전 브라우저 초안 정리는 실패할 수 있습니다. 오프라인 작업본에서 브라우저 저장에 실패하면 저장 완료로 처리하지 않으며, 별도의 `내보내기`로 현재 내용을 파일에 보관할 수 있습니다.

## PREP 체크리스트

- PREP 체크 완료 여부는 보기 모드에서 바꾸며, 인증 후 즉시 서버에 저장되어 공개됩니다. 완료 항목은 완료 그룹 아래로, 해제한 항목은 미완료 그룹 맨 위로 이동합니다. 실패하면 원래 상태로 돌아가고 `재시도`를 제공합니다.
- 체크리스트의 `목록 편집` 창에서 항목을 추가·수정·삭제하고 위·아래 버튼으로 순서를 바꿉니다. 창의 `저장`을 누르면 바로 서버에 반영됩니다. 새 항목은 미완료로 시작하며, 취소하거나 Esc로 닫으면 목록 변경을 버립니다. 체크 완료·목록 저장은 다른 일정·가계부 초안을 함께 공개하지 않습니다.
- 오프라인 작업본의 체크 완료·목록 변경은 이 브라우저에 저장됩니다. 온라인 반영에는 작업본 불러오기와 공유 저장이 필요합니다.
- 초안 복구를 보류한 상태에서도 체크 완료·목록 저장은 가능합니다. 보류한 초안은 그대로 보관되며, 새로고침 후 다시 복구할 수 있습니다.

## 일정과 시간 입력

- 일정은 시간·세로선·마커·카드로 이어지는 타임라인이며, 편집 모드에서 일정별 사진과 HTTPS 지도 링크를 첨부할 수 있습니다.
- 새 일정의 제목·장소/메모·주의사항은 안내 문구를 지우지 않고 바로 입력합니다. 안내는 저장되지 않으며, 보기 화면에서는 빈 제목을 `제목 없음`으로 표시하고 빈 메모·주의사항은 숨깁니다. 기존에 저장한 내용은 그대로 유지합니다. 문자 시간(미정 등)과 사진 설명은 편집창을 열면 전체 선택되어 바로 바꿀 수 있습니다.
- 일별 일정의 편집 모드에서 `일정 시간 추가` 또는 카드의 `시간 설정`을 누르면 시작 시간과 선택적인 종료 시간을 따로 입력합니다. 흐린 `09:00` 예시 위에 숫자 4자리를 입력하면 시·분 자리만 덮어쓰며 콜론은 자동으로 건너뜁니다. 예시는 실제 값이 아니므로 네 자리를 모두 입력해야 하며, 종료 시간을 비우면 시작만, 둘 다 비우면 미정으로 저장합니다. 기존 시각도 숫자를 덮어쓰거나 선택한 부분만 수정할 수 있고, 삭제하면 해당 자리의 예시가 다시 보입니다. `오전·오후·미정 등` 방식에서는 자유롭게 시간대를 적을 수 있습니다. KST 등 시간대 표기는 별도로 유지하며 시작·종료에 같은 기준을 적용합니다. 종료가 시작보다 이르면 다음 날 종료로 안내합니다. 적용 전 취소하면 일정은 바뀌지 않고, 적용한 변경은 실행 취소·다시 실행이 가능합니다.
- 일별 일정의 편집 모드에서 카드의 `일정 분류`를 선택할 수 있습니다. 기본값 `자동 (현재 분류)`은 제목·보조 태그를 따르며, 관광·식사·이동·숙소·휴식·기타를 직접 선택하면 해당 분류와 색상을 우선 적용합니다. 수동 선택은 제목을 바꿔도 유지되고, `자동`으로 되돌리면 현재 제목으로 다시 분류합니다. 분류 선택은 일정과 함께 저장·복원되고 실행 취소·다시 실행 및 오프라인 작업본에서도 유지되며, 버전·불러오기 비교에 분류 변경이 표시됩니다.

## 시간표

- `시간표`를 누르면 현재 불러온 일정을 날짜×시간으로 비교하는 보기 전용 화면이 열립니다. `1일`과 `전체` 보기를 제공하며 PC는 전체, 모바일은 1일 보기가 기본입니다. 날짜 이동은 1일 보기에서 사용하며, 전체 보기를 거쳐 돌아와도 선택했던 날짜가 유지됩니다. 일정 카드를 누르면 설명·주의사항·사진·지도 등 원래 상세 정보가 열립니다.
- `전체` 시간표는 모든 날짜 열과 시간축을 보여주는 `한눈에 보기`입니다. 넓은 화면에서는 한 화면에 압축하고, 800px 이하에서는 날짜 열의 너비를 확보해 좌우로 스크롤합니다. 작은 화면에서도 일정 이름과 시각을 표시하며 왼쪽 시간축은 고정됩니다. 상단의 시간 미정·종일·다른 시간대 일정은 일부 이름과 개수로 요약합니다. 일정을 누르면 상세 내용이 열리고, 날짜 제목을 누르면 해당 날짜의 1일 보기로 이동합니다.
- 시간표의 점선 카드는 시작 시각만 있는 일정입니다. 종료 시간을 추정하지 않으며, `09:00~11:00`처럼 구간이 명시된 경우에만 길이를 시간에 비례해 표시합니다. 겹치는 카드는 나란히 배치하고, 자정을 넘는 구간은 다음 날짜에 이어 표시합니다.
- `오전`, `미정`, `종일` 등 정확한 시각이 없는 일정과 KST 등 목적지 시간대와 다른 일정은 상단에 원래 표기로 모읍니다. 종류는 일정명과 보조 태그의 키워드로 자동 분류하며, 새 일정이나 이름을 수정한 일정도 시간표를 열 때 다시 분류합니다. 관광은 초록, 식사는 주황, 이동은 파랑, 숙소·휴식은 보라, 분류되지 않은 일정은 회색입니다. 예를 들어 `박물관 관람`, `점심 식사`, `공항 이동`은 해당 색상이 적용되지만 키워드가 없는 `새 일정`이나 장소명만 있는 일정은 기타로 표시될 수 있습니다. 1일 보기 하단에는 그날 등록된 체크인·숙박과 이동 내역을 요약합니다. 소요 시간이 없는 이동은 미정으로 표시합니다.
- 시간표 보기·날짜 이동은 여행 데이터나 초안을 변경하지 않습니다. 편집은 기존 일별 일정에서 진행하며, 인쇄·공유용 사본은 기존 일별 일정 형식으로 내보냅니다. 오프라인 작업본에서는 시간표도 사용할 수 있습니다.

## 사진과 지도

- 지도는 장소명과 외부 지도 URL을 저장하는 방식이므로, 오프라인 파일에서도 링크는 보이지만 실제 지도를 열 때는 인터넷 연결이 필요합니다.
- 사진 개수에는 제한이 없습니다. 추가한 사진은 우선 초안에만 보관되고 최종 저장할 때 업로드됩니다. 업로드 전에 WebP 큰 이미지(최대 1600px)와 썸네일(최대 480px)로 압축하며, WebP 출력 미지원 시 JPEG를 사용합니다. 압축 결과는 파일당 5MB 이하여야 하며, 화면에서는 썸네일을 지연 로드합니다. 개별 원본 파일은 20MB까지 선택할 수 있습니다.
- 사진 존재 확인은 요청당 10초, 업로드와 내보내기용 다운로드는 요청당 60초로 제한합니다. `작업 취소`를 누르면 진행 중인 사진 통신을 중단합니다. 실패·취소해도 초안은 유지되며 연결을 확인한 뒤 다시 시도할 수 있습니다. 오프라인 작업본은 사진 다운로드에 실패하면 생성하지 않고, 인쇄·공유용 사본은 해당 사진의 온라인 주소를 사용합니다.
- 화면에서 사진을 삭제해도 이전 버전에서 복원할 수 있도록 서버의 사진 파일은 즉시 삭제하지 않습니다.

## 가계부

- 가계부는 보기 모드에서도 날짜·카테고리·항목·금액·통화를 추가·수정·삭제할 수 있습니다. 실제 변경 시 유효한 편집자 세션을 확인하며, `변경사항 저장` 전까지는 공개되지 않습니다. 저장을 기다리며 입력한 다음 항목의 내용은 저장 완료 후에도 유지됩니다.
- 다른 사람의 저장이나 앱 복귀·재연결로 공유본이 갱신되어도 아직 `추가`하지 않은 입력과 커서 위치는 유지됩니다. 선택한 카테고리가 삭제되면 사용 가능한 카테고리로 바뀝니다. `추가` 전 입력은 초안에 보관되지 않습니다.
- 가계부 탭의 `가계부 설정`에서 수동 환율과 카테고리를 관리합니다. 카테고리를 삭제하면 연결된 내역은 `삭제된 카테고리`로 이동합니다.
- 가계부는 예산 진행률, 카테고리·검색 필터, KRW/USD 합계, 원화 환산 합계와 카테고리별 합계를 보여주며 현재 목록을 안전한 CSV로 내보낼 수 있습니다.

- 환율은 자동 시세가 아닌 수동 입력값입니다. USD 금액에 입력 환율을 곱해 원화 환산 합계를 계산합니다.
- 내역은 등록순으로 표시되며 위·아래 버튼으로 순서를 바꿀 수 있습니다. 항목 삭제에는 확인 절차가 있습니다.

## 버전 비교와 복원

- 저장본은 메모와 함께 최근 50개까지 보관됩니다. `버전 관리`는 목록에서 본문을 한꺼번에 내려받지 않고 선택한 버전만 불러와 비교·미리보기·복원합니다. 미리보기 중에는 편집·일반 저장을 막고 원래 초안을 보존합니다. 과거 내용을 공유본에 반영하려면 `복원` 확인을 거쳐야 합니다.

실행 취소는 현재 편집의 임시 기록이고, 버전 관리는 서버에 저장된 기록입니다. 복원은 선택한 과거 내용을 새 버전으로 저장합니다.

## 오프라인 작업본과 인쇄·공유용 사본

- `내보내기`에서 목적에 따라 `오프라인 작업본` 또는 `인쇄·공유용 사본`을 선택합니다.
- `오프라인 작업본`은 사진까지 파일 안에 포함하며 인터넷 없이 편집할 수 있습니다. 사진이 많아 100MB를 넘으면 다운로드 전에 경고합니다.
- 오프라인 작업본에서 편집한 뒤 저장하면 새 작업본이 내려받아집니다. 온라인 페이지의 `편집본 불러오기`는 최신 공개본과 달라진 일정을 먼저 보여주며, 확인한 내용은 초안으로만 적용됩니다. 별도로 `저장`해야 공개됩니다.
- 다른 여행·손상된 파일·지원하지 않는 버전은 기존 초안을 유지한 채 거부합니다. 구버전 작업본은 일정과 체크 상태를 보존해 불러옵니다. 비교 중 공유본이 바뀌면 갱신된 차이를 다시 확인해야 적용됩니다.
- `인쇄·공유용 사본`은 편집 기능과 Supabase 연결을 제거한 읽기 전용 스냅샷입니다. 가능한 사진은 파일에 포함하며, 포함하지 못한 사진과 지도 링크를 열 때만 인터넷 연결이 필요합니다.

## 홈 화면 앱 설치와 오프라인 이용

HTTPS로 배포한 주소에서 설치하면 지정된 아이콘과 이름으로 홈 화면에서 실행되며, 지원하는 브라우저에서는 주소창 없는 독립 화면으로 열립니다.

- Android Chrome: 메뉴 → `홈 화면에 추가` → `설치` (브라우저 버전에 따라 메뉴 이름이 다를 수 있습니다).
- iPhone Safari: 공유 → `홈 화면에 추가` → 표시되는 경우 `웹 앱으로 열기`를 켜고 추가합니다.
- 처음에는 인터넷에 연결해 페이지와 최신 공유 일정이 모두 열린 뒤 사용하세요. 설치만으로 모든 여행 사진이 오프라인 저장되는 것은 아닙니다.
- 온라인에서는 화면·설정 파일을 먼저 갱신하고, 네트워크 실패 또는 4초 동안 응답이 없으면 저장된 파일로 앱을 엽니다. 공유 일정 조회도 8초로 제한하여 응답 없는 Wi-Fi에서 계속 로딩되지 않게 합니다. 조회 실패 시 일정 데이터는 기존 IndexedDB 공개본에서 읽으며 저장 시점이 표시됩니다. 로컬 공개본이 없으면 기본 일정임을 표시합니다.
- Supabase 인증·일정 API·사진 Storage 요청은 서비스 워커가 캐시하지 않습니다. 로그인, 서버 저장, 외부 지도와 업로드 사진은 인터넷이 필요합니다. 사진까지 확실히 보관하려면 기존 `오프라인 작업본` 내보내기를 사용하세요.
- 일반적인 재연결은 기존 동기화를 사용합니다. SDK까지 로드하지 못한 상태에서 시작했다면 인터넷 연결 후 앱을 다시 열거나 새로고침하세요.
- 캐시는 브라우저의 저장 공간 정리로 삭제될 수 있습니다. 내려받은 작업본과 달리 영구 백업은 아닙니다.

## 화면 테마

앱 상단의 `화면 테마`에서 `밝게`(기본값), `어둡게`, `기기 설정`을 선택합니다. 로그인 없이 사용할 수 있고, `기기 설정`은 브라우저의 `prefers-color-scheme` 변경을 실시간으로 따릅니다.

- 선택은 현재 브라우저의 localStorage에 배포 디렉터리별 키(`westbound:theme:<경로>`)로 저장됩니다. Chrome과 삼성 인터넷 사이에는 공유되지 않습니다. 여행 데이터·초안·공유 저장·버전 이력에는 포함되지 않습니다.
- 저장소 접근이 차단되거나 용량이 부족하면 화면에 안내하고 이번 실행에만 선택을 적용합니다. 사이트 데이터를 삭제하면 기본값으로 돌아갑니다.
- 테마 초기화 코드와 CSS는 HTML에 포함되어 오프라인에서도 동작합니다. 편집 가능한 작업본은 테마 기능과 원래 배포 경로만 유지하며, 작성자의 테마 선택은 내보내지 않습니다. `file://` 문서의 선택 저장은 브라우저의 로컬 파일 저장소 지원에 따라 달라집니다.
- 인쇄·공유용 사본은 밝은 테마이며 선택 UI를 제거합니다. 앱에서 인쇄할 때도 밝은 색상을 사용합니다.
- 삼성 인터넷의 **웹 콘텐츠 강제 다크모드**가 사이트 색상을 다시 변환하는 경우가 있습니다. 앱은 밝은 모드에 `color-scheme: only light`를 명시하지만, 브라우저 설정을 직접 끄거나 강제 변환 여부를 신뢰성 있게 감지할 수는 없습니다. 선택과 다르게 표시되면 삼성 인터넷 설정 → 웹페이지 보기 및 스크롤 → 다크 모드에서 웹 콘텐츠 강제 다크모드를 끄고 앱을 다시 여세요. 메뉴 이름은 브라우저 버전에 따라 다를 수 있습니다.

새 버전 배포 후 인터넷에 연결한 상태에서 앱을 다시 열면 화면이 갱신됩니다. 열려 있는 앱 창을 모두 닫고 다시 열면 대기 중인 서비스 워커도 활성화됩니다. 저장하지 않은 편집 중에는 강제 새로고침하지 않습니다.

## 문제가 생기면

저장 실패·사진 업로드·화면 갱신 문제는 [문제 해결](OPERATIONS_KO.md#troubleshooting)을 참고하세요. 저장 여부가 불분명하면 초안을 유지하고 화면 안내를 확인합니다.
